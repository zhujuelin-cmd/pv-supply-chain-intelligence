# 光伏供应链跨市场研究终端

基于 Python + Streamlit 的证据优先研究辅助产品，运行时调用 **扶摇 API + iFinD MCP** 获取真实数据，并保留公开资料快照作为显式降级。**研究辅助工具，不构成投资建议。**公开资料快照截止 **2026-10-27**。

## 目标用户

买方/卖方研究员、产业分析师、投研数据产品经理，以及需要审计结论来源的研究团队。

## 三问题架构

1. **Q1 产业链证据**：多晶硅→硅片→电池片→组件→胶膜/玻璃/支架→逆变器→EPC→运营。Level严格按“L1收入证据、L2官方经营或扩张证据但缺独立收入、L3战略布局、L4传闻/推测”归一；无收入数字不得L1。
2. **Q2 冲击传导**：硅料+20%、美国组件关税+25%、欧洲装机目标上调、钙钛矿重大突破。每个情景包含Graphviz链路、三时间段矩阵、公司/财务指标、推断类型、公式与失效条件。
3. **Q3 中外可比**：通威-Wacker、隆基-First Solar、晶科-SunPower、阳光-Enphase。并列展示可比性、不可比性、对标指标、会计/币种/期间差异；SunPower主体断裂显著警示。

## AI角色与验证

AI用于将指定研究材料转为结构化候选证据、设计信息架构、生成测试与一致性检查。AI不作为事实来源；每条产品结论均落到统一 `Claim` 账本，由公开原始URL、报告期、检索日、证据类型和限制支撑。详情见 `AI_USAGE_LOG.md`。

## 数据使用

- 运行时通过扶摇 API 拉取 A 股利润表，通过 iFinD MCP 拉取公司财务与光伏产业链指标。
- 接口异常时明确提示并回退至 `data/public/` 可审计快照，不生成或模拟数据。
- 星级固定：财报/公告=⭐⭐⭐⭐；扶摇/iFinD/行业权威=⭐⭐⭐；头部研报=⭐⭐；媒体=⭐。
- 本项目**不读取、不复制、不嵌入任何用户上传Excel**。
- 上传资料仅用于理解行业背景，未进入产品数据层。
- `data/public/` 为可审计快照，不含接口伪造值。

## 更新机制

1. 在 `data/public/claims.json` 新增带完整审计字段的 claim。
2. 在 Q1/Q2/Q3 结构文件中只引用存在的 `claim_id`。
3. 保留原报告期，并更新 `retrieved_at` 和快照元数据。
4. 运行 `pytest -q` 与 `python scripts/e2e_validate.py`。
5. 扶摇/iFinD 适配器先验证真实运行时数据；失败时继续显式回退，不缓存伪数据。

## 运行

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

接口密钥通过项目根目录 `.env` 或部署环境变量注入：`FUYAO_API_KEY`、`IFIND_API_KEY`。`.env` 已加入 `.gitignore`，不得提交到仓库。

离线运行指快照浏览不依赖网络；实时数据与原始来源链接需要联网。

## 测试

```bash
pytest -q
python scripts/e2e_validate.py
```

覆盖证据字段、星级、日期、Q1分级、四情景、美国关税五步链、接口降级、SunPower断点、合规和Streamlit冒烟。详见 `TESTING.md`。

## 部署

本项目未部署。任意支持 Python 3.11+ 的环境均可按上方命令启动；生产环境建议固定依赖、使用只读公开快照并记录更新审计日志。

## 边界

- 快照日不等于所有公司的报告期；各条保留各自 `report_period`。
- 情景是压力测试，不代表政策已经发生；无可靠数据时只给方向、敏感度和公式。
- 跨公司毛利率受会计、业务、政策激励和币种影响，不直接用于估值结论。
- 接口适配器已实现扶摇 REST 与 iFinD Streamable HTTP MCP 调用；运行时失败会回退公开快照。
