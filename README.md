## 1. 产品一句话定位

以可追溯证据连接**“产业链归属—外部冲击—公司财务—跨市场比较”**的投研辅助终端，解决传统投研中“概念与真实业务脱节、外部冲击传导路径模糊、中外公司表面财务机械横比”三大痛点。

---

## 2. 目标用户

- **买方 / 卖方股票研究员**：快速梳理产业链分层，核实上市公司真实业务归属，评估宏观政策与供需冲击对财务报表的影响。
- **新能源产业分析师**：跟踪光伏主链与辅材价格传导机制，建立带时间维度与失效条件的情景分析框架。
- **投研数据产品经理**：参考证据等级约束（L1–L4）与可审计数据血缘（Claim Ledger）的信息架构设计。
- **投资决策与风控团队**：对研究结论进行底层事实穿透与合规边界审核，防范伪概念炒作与跨市场机械对标风险。

## 3. 三大核心设计（三问题架构）

产品摒弃传统数据库简单堆砌指标的做法，围绕投研中最核心、最难回答的三个问题展开：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                       光伏产业链传导分析仪 三问题架构                     │
├───────────────────┬───────────────────────────┬─────────────────────────┤
│ Q1 产业链证据     │ Q2 冲击传导               │ Q3 中外可比             │
│ 公司真的属于该环节吗?│ 外部冲击如何进财务报表?   │ 中外表面数字能直接比吗? │
├───────────────────┼───────────────────────────┼─────────────────────────┤
│ • 9段主辅链拓扑   │ • 4类外部冲击情景         │ • 4组中外龙头对标       │
│ • L1–L4严格分层   │ • 0-3月/3-12月/1年以上矩阵│ • 拆解可比与不可比维度  │
│ • 无收入不标L1    │ • 量化公式与失效条件      │ • 会计/准则/45X差异校正 │
│ • 逐条带原始URL   │ • 真实接口+E2E五步验证    │ • SunPower破产断点警示  │
└───────────────────┴───────────────────────────┴─────────────────────────┘
```

1. **Q1 产业链证据**：覆盖从硅砂、多晶硅、硅片、电池片、组件、胶膜/玻璃/支架、逆变器到 EPC、电站运营的完整链条。严格执行 **L1（明确收入证据）**、**L2（官方经营/扩张但缺独立收入）**、**L3（战略布局）**、**L4（传闻/推测）** 的证据分层。**没有独立分部收入数字，一律不得标为 L1**。
2. **Q2 冲击传导**：将宏观与行业冲击（如原材料涨价、关税上调、装机目标变化、技术突破）拆解为“冲击→成本/价格→业务运营→财务指标”的有向传导路径。提供 **0–3月（即期交付）**、**3–12月（订单/毛利）**、**1年以上（产能/格局）** 三阶段影响矩阵，并明确成立条件与失效条件。
3. **Q3 中外可比**：拒绝机械横比中外公司的表面毛利率。深入拆解技术路线（晶硅 vs 薄膜）、业务模式（制造业 vs 安装服务商）、会计准则（中国准则 vs US GAAP vs IFRS）、报告期、币种及政策补贴（如美国 IRA Section 45X 抵免）对报表造成的实质差异，给出针对性对标指标建议。

## 4. 核心功能模块说明（7 个页面）

系统由 7 个核心页面组成，各页面分工与输出如下：

| 序号 | 页面名称 | 核心功能与输出 | 关键交互与展示位置 |
|:---:|---|---|---|
| **1** | **研究主页** | 展现产品全景概览指标（产业链公司数、L1 收入证据数、固定情景数、中外配对数）、三大核心问题导航导览、数据运行健康状态、基准日说明。 | 顶部指标卡、中部三问题卡片、底部实时数据状态指示灯。 |
| **2** | **📖 使用指南** | 针对「行业新手」、「事件研究」、「中外对标」三类典型投研任务提供最佳阅读路径推荐，详细说明可调变量、各页面核心产出位置及数据状态判读标准。 | 任务场景选择卡片、可调参数表格、产出位置映射表。 |
| **3** | **🏭 行业背景** | 展现从硅砂到并网发电的光伏主链与辅材、政策拓扑图（Graphviz）；拆解上游/中游制造/辅材/下游代表企业与竞争要素；提供代表企业综合毛利率参考带；列出四大高频跟踪价格变量与海外政策环境。 | 顶部交互式全景图、四大环节 Tabs 折叠面板、毛利率参考表、外链价格源。 |
| **4** | **Q1 产业链证据** | 提供 9 大环节的上市公司业务归属验证，执行严格的 L1–L4 证据等级归一；展示归一理由与结构化证据卡片（含原始报告 URL、报告期、星级、数据限制说明）。 | 环节下拉选择器、归纳汇总表、展开式详细证据卡片。 |
| **5** | **Q2 冲击传导** | 内置 4 个预设情景（硅料+20%、美国关税+25%、欧洲装机上调、钙钛矿突破）。展示有向传导图、0-3月/3-12月/1年以上三阶段时间矩阵、受损/受益标的、量化公式、失效条件，以及美国关税情景下的五步端到端校验链与真实数据模块。 | 情景切换下拉框、Graphviz 动态路径图、时间维度矩阵表、真实数据校验卡。 |
| **6** | **Q3 中外可比** | 提供 4 组中外代表公司对标（通威-Wacker、隆基-First Solar、晶科-SunPower、阳光-Enphase）。拆解为何可比、为何不可比、报告/会计差异，推荐对标指标，并对 SunPower 破产主体断裂提供高亮风险警示。 | 可比组选择框、综合可比度指标、差异对比卡片、主体断裂 Warning 框。 |
| **7** | **数据与来源** | 展示扶摇 API 与 iFinD MCP 运行时接口状态及回退机制，提供一键刷新实时数据功能；公示四级可信度规则；提供全量 28 条 Claim 的可审计证据账本（支持链接跳转）。 | 接口状态监控面板、一键刷新按钮、交互式证据账本 DataFrame。 |

## 5. 本地启动方式

本项目基于 Python 3.10+ 与 Streamlit 构建，支持快速本地运行：

### 步骤 1：克隆并进入项目目录
```bash
cd pv_supply_chain_intelligence
```

### 步骤 2：创建并激活虚拟环境
```bash
# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

# Windows
python -m venv .venv
.venv\Scripts\activate
```

### 步骤 3：安装依赖包
```bash
pip install -r requirements.txt
```

### 步骤 4：启动 Streamlit 本地服务
```bash
streamlit run app.py
```
启动成功后，浏览器访问 `http://localhost:8501` 即可体验。

## 6. 环境变量配置说明

项目支持通过根目录下的 `.env` 文件或系统环境变量注入外部数据接口凭据：

```bash
# 复制环境变量模板
cp .env.example .env  # 或直接新建 .env 文件
```

在 `.env` 中填入对应的 API Key（**占位符格式如下**）：

```ini
# 扶摇数据 API Key（用于拉取 A 股上市公司真实利润表与行情）
FUYAO_API_KEY=your_fuyao_api_key_here

# 同花顺 iFinD MCP 认证 Token（用于拉取产业链指标与财务问答）
IFIND_API_KEY=your_ifind_api_key_here
```

> **安全与降级说明**：
> 1. 项目 `.gitignore` 已配置忽略 `.env`，**请勿将包含真实密钥的文件提交到版本库**。
> 2. **无 Key / 离线运行保证**：若未配置环境变量或外部接口网络异常，系统适配器会自动探测并输出黄色 Warning 提示，同时**平滑降级至 `data/public/` 官方公开资料快照**，确保全部 7 个页面与三问题主链路 100% 完整可用，绝不报错或崩溃。

## 8. AI 角色与人机边界

- **AI 的角色**：负责将多源异构公开研报、行业报告与财报材料进行结构化归纳；辅助设计统一 Claim/Evidence schema 与信息架构；生成 Graphviz DOT 拓扑代码；编写自动化测试用例与合规扫描规则。
- **人机边界与硬性约束**：
  1. **AI 绝不作为事实来源**：系统展示的每一个定量数据和定性结论，必须映射到具体的 `claim_id`，并由公开合规的原始 URL、报告期和检索日作为支撑。
  2. **禁止编造与模拟数据**：接口异常时仅回退到可审计的静态快照，绝不使用 LLM 幻觉生成财务或行情数字。
  3. **数据隔离原则**：本项目**不读取、不复制、不嵌入任何用户本地未公开 Excel**，全部使用公开财报与权威资料。

## 10. 已知边界与未做事项

### 已知边界
1. **报告期独立性**：快照基准日（2026-10-27）为数据检索与审计基准日，不同上市公司的具体财务数据保留各自真实的报告期（如 2025 年报、2026 半年报、2026Q2 季报），不强行进行时间对齐。
2. **情景推演的条件性**：Q2 情景推演属于严谨的**压力测试模型**，不代表对应政策已板上钉钉；推演结论附带严格的成立条件与失效条件。
3. **跨市场指标不可直接估值**：由于中外会计准则、产品技术路线与政策补贴（如 45X 抵免）的实质差异，毛利率等单一指标不得直接用于绝对估值横比。

### 未做事项
- ❌ **不提供买入/卖出推荐、目标价预测或投资收益承诺**（严格遵守证券投顾合规红线）。
- ❌ **不开放任意本地 Excel 上传**（防止未经审计的不可信数据污染系统）。
- ❌ **不接入证券实时高频撮合交易**。
- ❌ **不将破产重组前后的 SunPower 财务序列进行无缝机械拼接**（严格设立法律主体断点）。
